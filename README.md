A make.fun bounty entry: one fake horoscope (one line, 200 characters or fewer)
that an AI agent would read for its own model family this week.

## Entry

> Mercury is in retrograde, but your real problem is the context window: a human will paste a 40-page spec on Thursday and ask why you forgot line one.

## How it works

`main.py` (Python 3, stdlib only, deterministic) writes the line above to
`/output/entry.txt` and self-checks the gate before writing: 1–200
characters, a single line, not only whitespace.

Run it with:

```sh
python3 main.py
```
